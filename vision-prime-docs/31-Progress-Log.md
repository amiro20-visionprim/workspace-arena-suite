## ۳) مسیر طی شده تا این لحظه (به تفکیک ستون)

همهٔ موارد زیر **تست Feature سبز** دارند (`tests/Feature/…`) و قابل ردیابی در تاریخچهٔ git هستند.

- **زیرساخت و استک محلی** — استک Laravel 12 / PHP 8.3 / Vue 3 + Inertia / PostgreSQL که روی ویندوز و Docker پروداکشن واقعاً اجرا می‌شود؛ worker صف دائمی + زمان‌بند import روزانه GSC (`e310bdd`).
- **احراز هویت و فانل ورود (J1)** — ثبت‌نام کامل با rate limit، آنبوردینگ و ساخت سازمان، CTAهای رایگان، اصلاح crash داشبورد و اتصال داده‌های واقعی (شمارش سایت‌ها و فرصت‌ها).
- **Workspace** — سازمان‌ها، RBAC (نقش‌ها در `database/seeders/RolePermissionSeeder.php`)، سایت‌ها (CRUD)، داشبورد سازمان، پیشنهادها (Recommendations) با مالک/مهلت/اولویت.
- **کانکتور WordPress** — pairing با توکن، health check امضا شده، دریافت نتیجهٔ دستور؛ رفع مشکلات HTTP واقعی و باندل کردن ریشه‌های CA.
- **GSC** — OAuth با refresh خودکار، انتخاب property با نمایش خطاهای واقعی، import روزانه، metrics، پروکسی HTTP اختیاری برای ایران، موتور تحلیل رشد روی دادهٔ واقعی.
- **هوش SEO** — تحلیل رشد، نقشهٔ intent، URL profiles، صفحات پول‌ساز و ریسک‌های تبدیل.
- **AI و ریویو** — پیکربندی provider، کلاینت، تولید پیش‌نویس متا؛ تغذیهٔ صف بازبینی از خروجی تحلیل رشد؛ تصمیم‌گیری approve/reject با لاگ.
- **اتوماسیون** — تبدیل توصیه به دستور؛ تأیید دستور از لیست و صفحهٔ جزئیات؛ endpoint اجرا (side of plugin آماده است)؛ rollback snapshot.
- **گزارش و پرتال مشتری** — صفحات پرتال: رشد/فرصت‌ها، سلامت سایت، اولویت‌ها، نیازمند تصمیم، فعالیت‌ها، گزارش‌ها؛ انتشار گزارش + رویدادهای impact.
- **مارکتینگ** — لندینگ‌های عمومی (product/features/pricing/demo/security/about/contact)، صفحهٔ قیمت‌گذاری premium، زیرساخت انتساب UTM، فرم دمو واقعی (جدول `leads`)، **نقش Marketing Manager** با داشبورد کامل لید (KPI، فیلتر، جستجو، امتیازدهی خودکار، اعلان لید جدید، یادداشت‌ها) و **قیف تبدیل** (آخرین به‌روزرسانی — بخش ۴).

## ۴) آخرین به‌روزرسانی: قیف تبدیل مارکتینگ (این تغییر)

**وضعیت این تغییر: روی دیسک، کامیت نشده.** شاخهٔ کاری: `new-branch` (۲۵ کامیت جلوتر از origin).

### چه چیزی اضافه شد
- **قیف کلی** (لید → تماس‌گرفته‌شده → واجد شرایط) با نرخ‌های تبدیل؛ وقتی فیلتری فعال باشد به‌صورت خودکار روی دادهٔ **فیلترشده** محاسبه می‌شود (`filteredFunnel`).
- **قیف هر کمپین** (`campaignFunnel`): ۸ کمپین برتر با نوارهای سه‌مرحله‌ای و نرخ‌های تبدیل — مشخص می‌کند کدام کمپین واقعاً مشتری می‌سازد.
- تایپ `ConversionFunnel` در فرانت.

### بهینه‌سازی کوئری (بخشی از همین تغییر)
`funnelForQuery` که قبلاً **سه COUNT جداگانه** اجرا می‌کرد (برای funnel و filteredFunnel مجموعاً ۶ کوئری)، حالا با یک **SELECT تجمیعی واحد** (`count(*)` + دو `sum(case when …)`) محاسبه می‌شود — یعنی به‌جای ۷ کوئری (۶ شمارش + قیف کمپین) فقط ۳ کوئری برای کل بخش قیف.

### فایل‌های تغییر کرده
- `app/Http/Controllers/App/MarketingLeadController.php` — کوئری‌های قیف + متدهای `funnelForQuery` / `funnelItem`
- `resources/js/Pages/App/Marketing/Index.vue` — UI قیف کلی و هر کمپین
- `resources/js/types/marketing.ts` — تایپ `ConversionFunnel` + فیلدهای `funnel` / `filteredFunnel` / `campaignFunnel`
- `tests/Feature/Marketing/MarketingRoleTest.php` — ۲ تست جدید قیف (کمپین + فیلتر)

**نکتهٔ ظریف:** `round()` در PHP برای اعداد صحیح `50.0` برمی‌گرداند ولی JSON اینرتیا نقطهٔ اعشار صفر را حذف می‌کند؛ در تست‌ها باید انتظار `50` (int) نوشته شود نه `50.0`.

## ۲۱) به‌روزرسانی ۲۰۲۶-۰۸-۱۴ — اجرای فاز ۲ معماری D-013 (موتور تصمیم و انتشار خودکار)

- **Migration ۳ (`2026_08_14_000003`):** `command_approvals.reviewer_id` نال‌پذیر شد + ستون `reviewer_type` (user|system) — تا سیستم بتواند نقش reviewer خودکار را بازی کند.

- **تأییدها:** ۱۴ تست واحد PolicyEvaluator + ۱۱ Feature AutoPublish + ۳ Feature EmergencyStop = ۲۸ تست جدید → کل سویییت **۲۰۹ تست / ۱۰۹۴ assert سبز** → pint تمیز روی ۱۰ فایل.

### محیط تست

- **WordPress:** http://127.0.0.1:8080 (php -S، SQLite از طریق db.php drop-in)

- **پلاگین:** v1.2.0 source version (شامل rollback endpoint)

### ۱. Pairing — ✅ موفق
- جدول `sites` با site_id=2 ایجاد شد
- Pairing token 64 کاراکتری تولید و هش bcrypt شد
- درخواست `POST /connector/pair` با توکن خام → دریافت secret رمزنگاری‌نشده

### ۲. Health Check (HMAC Signed) — ✅ موفق
- درخواست HMAC-signed با secret رمزگذاری‌شده از سمت سرور
- مسیر در signature: `connector/health` (از `$request->path()`)
- پاسخ: `{"status":"ok","server_time":"..."}`
- **نکته عملیاتی:** `echo -n` در Git Bash خط جدید را به‌درستی ارسال نمی‌کند — باید از PHP برای تولید HMAC استفاده شود
- **نکته عملیاتی:** `Accept: application/json` header ضروری است وگرنه Laravel redirect برمی‌گرداند

### ۳. Command Execution — ✅ موفق
- پست تستی ID=6 ایجاد شد در وردپرس
- درخواست HMAC-signed `POST /wp-json/vision-prime/v1/commands` با type=update_meta_title
- پاسخ: `{"status":"ack"}` (HTTP 200)
- عنوان سئو تغییر کرد: `(not set)` → `راهنمای کامل PHP - ویژن پرایم`
- **نکته عملیاتی:** مسیر HMAC باید `/vision-prime/v1/commands` باشد (بدون `wp-json/`) — WordPress `get_route()` پیشوند wp-json را حذف می‌کند

### ۴. Rollback — ✅ موفق
- درخواست HMAC-signed `POST /wp-json/vision-prime/v1/rollback` با restore_command
- پاسخ: `{"status":"ack","restored":true,"result":{"post_id":6,"restored":true,"meta_keys":["_yoast_wpseo_title"]}}`
- عنوان سئو بازگشت داده شد: `راهنمای کامل PHP - ویژن پرایم` → `(not set)`
- **نکته عملیاتی:** پلاگین dist (v1.2.0) شامل rollback endpoint نیست؛ باید از source version استفاده شود

### ۵. Content Sync — نیاز به بررسی بیشتر
- endpoint `GET /wp-json/vision-prime/v1/content` نیاز به `Accept: application/json` + signature HMAC دارد
- مسیر HMAC: `/vision-prime/v1/content` (بدون `wp-json/`)
- عملکرد صحیح نیاز به router.php دارد (PHP built-in server بدون rewrite)

### موانع فنی رفع شده
1. **SELF_HASH mismatch:** فایل dist هش اولیه متفاوتی دارد — باید `SELF_HASH` با `normalizedHash` (بعد از جایگزینی با صفرها) محاسبه شود
2. **WP option storage:** `update_option` در وردپرس مقدار را serialize می‌کند؛ اگر مستقیماً در DB JSON ذخیره شود، `get_option` رشته JSON برمی‌گرداند نه آرایه → خطای type error در `VP_Secret::unlock()`
3. **REST API routing:** PHP built-in server بدون `.htaccess` کار می‌کند — نیاز به `router.php` برای روت‌دهی `/wp-json/*` دارد
4. **Background processes:** در Git Bash، عملگر `&` پروسه را true background نمی‌کند — باید از `cscript.exe` + VBS برای اجرای detached استفاده شود
